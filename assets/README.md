# assets/ — 放图的地方

把立绘文件丢进这个文件夹，页面会自动使用它；不放图时，页面回退到内置的手绘 SVG 立绘。

## 固定文件名（重要）

| 文件名 | 用途 |
| --- | --- |
| `portrait.png` | **普通形态**立绘（左颊有疤 + 三角巾） |
| `portrait-ego.png` | **神备形态**立绘（疤痕消失、面带光环）——可选 |
| `sword.png` | **长剑形态**立绘（遗剑区）——可选 |
| `sword-gun.png` | **枪械形态**立绘（遗剑区）——可选 |
| `avatar.png` | 主页头像（1:1）——可选 |

规则：

- 只放 `portrait.png` → 两种形态都用这一张。
- 两张都放 → 切换「普通 / 神备」时自动交叉淡入淡出。
- 剑立绘同理：只放 `sword.png`，切到枪形态时仍显示这张；`sword-gun.png` 也放进去则切换时替换。
- 文件名/后缀必须完全一致（小写 `portrait.png`）。若你的图是 `.jpg`，要么改扩展名，要么告诉我，我来改代码。
- 想用别的名字也行，告诉我文件名即可。

> **格式说明**：浏览器按文件内容（magic number）识别图片，不看重扩展名，所以 `.png` 名字下装 JPEG 也能正常显示——当前你放的三张就是这样，工作正常。唯一区别是 **JPEG 不支持透明**：若想让立绘与版位的蓝色辉光自然融合，建议导出**带透明的 PNG**。不改也能用。

## 剑立绘的推荐规格（sword / sword-gun）

- **横向长图**最好，比例约 **3:1 ~ 4:1**（例如 1600×520）。这一版位是横幅，横着的剑最合适。
- **透明底 PNG**（或纯黑底也可，版位本身是深色）。
- 如果是**竖版大剑**也没关系：显示方式为 `object-fit: contain`，会完整缩放居中、不裁切。竖图会显得偏小，但不会变形。
- 两张图的**朝向/比例尽量一致**，切换时视觉更稳。

## 推荐规格

- **比例 3:4**（例如 1200×1600、1500×2000）。版位本身是 3:4，比例不符会被裁切。
- **透明背景 PNG** 效果最好（版位自带深色底 + 蓝色辉光）。
- 构图：**头肩半身、人物居中**。显示时会以 `object-position: 50% 22%` 聚焦偏上，避免裁掉头部。
- 分辨率 ≥ 1200px 宽即可，太大无益（页面只当版位用）。

## 我可以怎么帮你接

1. **文件方式（推荐）**：把上面两个文件放进本文件夹 → 告诉我「放好了」→ 我渲染确认接线正确。
2. **聊天贴图方式**：直接把图贴进对话，我找出附件落盘位置、复制进本文件夹并按规范命名。
3. 如果是 **PSD/分层图**（例如三角巾单独一层），告诉我，我可以做成「切换形态时三角巾层单独淡出」的叠加效果。

> 注：我当前环境无图像识别能力，无法替你判断「好不好看」；我负责把图**正确地接进版位并保证两种形态切换无误**，审美把关请你自己看一眼。
